This release adds owner-authorized `app secrets reveal`, `app secrets delete` and `app sqlite download`. Reveal writes exact secret bytes to a new private file, or to deliberate `--stdout` output that is refused in JSON/agent mode. SQLite download creates a new private file containing a consistent business-data export; it excludes framework sessions, credentials, audit/replay records and copied freelist pages. Existing files and symlinks are never overwritten.

Deletion checks the current version and secret incarnation, sends no value, and reports uncertainty without retrying. A recreated logical name receives a different provider resource identity. Secret protocol 2 and the seventh owner permission, `secrets.delete`, require a matching Platform distribution; older contracts fail closed. This CLI release does not deploy that backend or migrate existing app databases.

Secret metadata, creation, rotation and request status remain available through `app secrets list/create/rotate/status`. Rotation stores another supplied value as a new version; it does not activate app bindings or revoke upstream credentials. The release retains company browser login, OS credential storage, immediate audited local-operator owner management, generated OpenAPI, authenticated app calls, invocation status and offline Bash/Zsh/Fish completion.

Native archives support Apple Silicon macOS 15+ and x86_64 glibc 2.39+ Linux. Archives include dependency notices, source identity, SHA-256 checksums and signed GitHub Actions provenance. The installer verifies attached Sigstore bundles without an employee GitHub login and preserves existing Platform operator installations. See docs/INSTALL.md.

Released v0.3.0 has genuine hosted macOS login and owner/create/rotate/status qualification, including denied nonowners, immediate owner grants, stale-version/request-reuse refusal and guarded synthetic cleanup. The new reveal/delete/SQLite endpoints still require separate hosted qualification on the matching deployment. Native provider checks and Linux Secret Service qualification do not establish live Linux browser/IAP access. Runtime activation, reconciliation, restoration and arbitrary SQLite queries remain separate work.
